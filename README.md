# Budgy

### 💡 Purpose
This is a purely vibe coded personal hobby project, made to make personal financing and budgetting easier and more automated. 

### 🚧 Scope
- This is not made to to be destributed and have its quirks, so this should be kept in mind when using.
- None of the code has been reviewed.
- There are no contact to any 3rd party services in this app except for Vercel (The hosting service), which stores the data Blobs for sharing ones Budgy.
- App only works for Arm64 Macs 

### 🚀 How to get started
1. Download latest release
2. Add App to Applications (Run .dmg)
3. Happy budgetting.
